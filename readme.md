# emilia.qa — QA Engineer Portfolio

A single-page portfolio site for a QA Engineer with a development background.

Static site: vanilla HTML, CSS and JS — no frameworks, no build step.

---

## About the Project

This is a personal portfolio website for a QA Engineer who works across manual
testing, test automation and development. The site is intentionally lightweight:
plain HTML/CSS/JS, modular CSS files per section, and a small set of JS modules
for navigation, the popup easter egg and the mini-game.
